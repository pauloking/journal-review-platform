# 开发路线与阶段验收（ROADMAP）

## 阶段规划

| 版本阶段 | 核心主题 | 关键交付与验收标志 | 当前状态 |
|---|---|---|---|
| **V0.1** | 平台基础骨架 + 首轮纵向闭环 | 10 份工程文档；Document IR；Knowledge/RuleRegistry；Router DAG；确定性规则与复算引擎；编辑裁决与工作台；Word 原生批注与综合报告 DOCX 导出；自动化全流程测试 | **本轮实现并验证** |
| **V0.2** | 稿件深度解析与结构增强 | 多级标题树、图表交叉引用配对、复杂合并单元格定位、跨版本文档对齐提示 | 规划中 |
| **V0.3** | 知识包扩展与期刊多配置 | 授权专业术语库管理 UI、多医学亚专科期刊配置包、规则灰度草案验证流 | 规划中 |
| **V0.4** | 受控 AI 语义审校接入 | 启用 `LLMCandidateExecutor`（复用 `aiService.ts` JSON 容错/时间基准），实现事实台账语义提取、摘要一致性、图文表一致性校验 | 骨架与适配器已预留 |
| **V0.5** | 编辑评估闭环与黄金测试平台 | 双编辑盲标仲裁工具、规则 Precision/Recall/F1 看板、版本间回归对比门禁 | 反馈表与统计接口已就绪 |
| **V1.0** | 编辑部试点交付版 | 身份认证与 RBAC、租户隔离、加密存储与保留策略、异步任务队列、真实脱敏医学稿件全量验收 | 规划中 |
