# 《GB 3100~3102-1993 量和单位》

> 依据编号：`STD-GB3100-3102` ｜ 层级：国家标准 ｜ 版本：1993 ｜ 生效日期：1994-07-01

## 1. 适用范围
适用于题名、摘要、引言、方法、结果、讨论、结论、正文与表格中的计量单位与物理量表达。

## 2. 核心编校要求
1. **废止非标准符号**：
   - `ppm` → 改为 `10⁻⁶` 或具体质量/体积浓度（如 `μL/L`、`mg/kg`）（`UNIT-PPM`）
   - `ppb` → 改为 `10⁻⁹` 或具体量（`UNIT-PPB`）
   - `ppt` → 改为 `10⁻¹²` 或具体量（`UNIT-PPT`）
   - `rpm` → 改为 `r/min`（转每分）（`UNIT-RPM`）
   - `cal` → 换算为 `J`（`1 cal = 4.184 J`）（`UNIT-CAL`）
   - `M`（克分子浓度）→ 改为 `mol/L`（`UNIT-M`）
   - `Eq` / `N`（当量/当量浓度）→ 改为 `mol` 或 `mol/L`（`UNIT-EQ`、`UNIT-N`）
2. **词头与复数禁用**：
   - 词头不得重叠（如 `mμm` 应改为 `nm`）（`UNIT-MUM`）
   - 单位符号不加英文复数 `s`（如 `60kgs` 应改为 `60 kg`）（`UNIT-KGS`）
3. **医学惯用压强单位换算提示**：
   - `mmHg`、`cmH₂O` 允许保留，但首次出现应注明与 SI 单位 `kPa` 的换算关系（如 `1 mmHg ≈ 0.133 kPa`）；同一文稿同单位仅提示一次（`UNIT-MMHG`、`UNIT-CMH2O`）。
