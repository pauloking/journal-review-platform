# 《全国科学技术名词审定委员会 规范医学名词》

> 依据编号：`STD-CNTERM-COMM` ｜ 层级：行业规范 ｜ 版本：现行审定版

## 1. 适用范围
适用于医学期刊全稿（题名、摘要、关键词、正文各章节及表格）的医学专业术语规范核查。

## 2. 维护原则与常见规范对照
本规范文档汇总 43 组医学高频误用术语与旧称（如 `心肌梗塞 → 心肌梗死`、`脑梗塞 → 脑梗死`、`脑溢血 → 脑出血`、`美尼尔病 → 梅尼埃病`、`适应症 → 适应证`、`禁忌症 → 禁忌证`、`综合症 → 综合征`、`抗菌素 → 抗生素`、`血色素 → 血红蛋白`、`食道 → 食管` 等）。

- **上下文防误报机制**：如「血压高」在后接 `于`/`升`（如「收缩压高于 140 mmHg」）时自动豁免；「人流」在后接 `量`/`密度` 等非医学语境时自动豁免。
- **可维护提示**：编辑部可在下方规则条目表中直接新增或修订本刊补充术语对照，保存前系统将自动通过正反例校验。
